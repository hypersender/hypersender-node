# Introduction

A robust Node.js / TypeScript SDK for interacting with the Hypersender Api.

# Installation

You can install the package via npm:

```bash
npm install hypersender-node
```

# Official Documentation

You can find the official documentation at [Hypersender Node SDK Documentation](https://docs.hypersender.com/v2/packages-and-sdks/node/installation).
